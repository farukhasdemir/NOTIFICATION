🚀 Modern Modal UI Component

A sleek and responsive modal component built with a clean modern design and smooth animations.
This project focuses on creating an elegant user experience with minimal styling and interactive transitions.

✨ Features
Responsive modal design
Smooth open/close animations
Minimal and modern UI
Easy to customize
Lightweight structure
Dark mode friendly 🌙
🛠️ Technologies Used
HTML5
CSS3
JavaScript
📌 Purpose

This project was created to practice modern frontend UI development and improve animation/interactivity skills.
